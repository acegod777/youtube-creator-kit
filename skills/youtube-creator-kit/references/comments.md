# Comment replies

The user pastes comments; nothing here reads or posts on YouTube.

## Sort first

Say how many fall in each group before writing anything:
1. **Questions** - answer them. Repeated questions are ideas for the next video; list them.
2. **Corrections** - if right, thank them plainly. Never argue about a fact you cannot check.
3. **Kind words** - reply to a few, briefly, picking up something specific they said.
   Fifty identical "thank you" replies look automatic.
4. **Bait, spam, rudeness** - no reply. Say which ones and move on.

## Writing

- Under 30 words, the answer in the first sentence.
- The user's tone from the channel profile. Devotional channels: warm and simple, a greeting
  the user uses (for example a religious or regional greeting) only if the profile says they use it.
- Reply in the language the comment was written in when the user can read it.
- Never promise a video the user has not agreed to make. No emoji unless the user uses them.

## Hand back

Each reply under the comment it answers, ready to paste, then which ONE comment to pin and why
(the question most viewers also have).
